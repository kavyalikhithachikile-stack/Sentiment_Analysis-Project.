SENTIMENT ANALYSIS PROJECT
OVERVIEW
This project uses Python and Machine Learning to classify text as Positive, Negative or Neutral.
TECHNOLOGIES USED
Python
Pandas
Scikit-learn
TF-IDF Vectorization
Logistic Regression
Google Colab
FEATURES
Text sentiment classification
Model training and testing
Accuracy evaluation
Prediction for user-entered sentences
HOW TO RUN
Open the Jupyter Notebook in Google Colab and run the code cells from top to bottom
LEARNING OUTCOMES
Understanding text preprocessing
Learning feature extraction using TF-IDF
Training a machine-learning model
Evaluating model performance
